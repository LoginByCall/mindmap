# Мост интерфейса и оболочки

Интерфейс (`web/`) общий. Оболочки: `mindmap.py` (Linux, GTK + WebKit2GTK) и `macos/main.swift` (macOS, WKWebView).

## Транспорт

- JS → оболочка: `webkit.messageHandlers.app.postMessage(JSON.stringify({id, cmd, args}))`.
- Ответ: оболочка вызывает `bridge.reply(id, значение)`; значение — JSON, `null` означает «отмена или ошибка».
- Оболочка → JS: `zoomBy(f, x, y)` (щипок в GTK; WKWebView отдаёт его странице сам, событиями `gesture*`), `dropUris([uri…])` (брошенный файл), `openFile(Файл)` (файл из Finder при открытом окне: спросит про несохранённое).
- До `app.js` оболочка выполняет `window.I18N = {словарь web/lang/<код>.json}; document.documentElement.lang = '<код>'`. Для русского словарь пустой.

## Файл

`{path, name, data}` — `data` содержит байты файла в base64 или `null`, если файла ещё нет. Разбор форматов (`.md`, `.mm`, `.opml`, `.xmind`) — в `web/formats.js`, оболочка его не делает.

## Команды

| cmd | args | Что делает оболочка | Ответ |
|---|---|---|---|
| `ready` | — | старт | `{file: Файл \| null, pdf: путь \| null}` — файл из командной строки или Finder, `--pdf <путь>` |
| `state` | `{dirty, name}` | заголовок окна `имя — Mind Map`, несохранённое — `●` в заголовке (GTK) или точка в кнопке закрытия (macOS); запоминает флаг | `true` |
| `quit` | — | закрывает окно так же, как кнопка закрытия (спросит про несохранённое) | `true` |
| `confirm` | `{text}` | диалог «Да / Нет» | `true / false` |
| `error` | `{text}` | диалог ошибки; в режиме `--pdf` — выход с кодом 1 | `null` |
| `open` | — | диалог открытия: `.md .markdown .mm .opml .xmind` | Файл \| `null` |
| `link` | `{href, base}` | `http(s) mailto ftp` → браузер; путь (относительный — от папки `base`, `~` раскрывается, `file:`) → карта открывается, если это существующий файл с расширением карты; иначе файл или папка показываются в файловом менеджере. Прочие схемы и отсутствующий путь → ошибка | Файл (карта) \| `null` |
| `save_dialog` | `{name}` | диалог сохранения; к имени без расширения карты добавляет `.mm.md` | путь \| `null` |
| `save` | `{path, data}` | атомарно пишет байты (`data` в base64): `path.tmp` → переименование | `{path, name}` \| `null` |
| `pdf` | `{path, w, h, name}` | печатает страницу в PDF размером `w × h` CSS px (1 px = 0,2646 мм, сторона ≤ 5 м), поля 0; `path` — `null` → диалог сохранения с именем `name`. Печатается разметка `@media print` (`#print`). После `--pdf` выходит | путь \| `null` |

Ошибки чтения и записи оболочка показывает сама и отвечает `null`: данные в редакторе остаются целы.

## Окно

- Закрытие окна с `dirty` спрашивает «Есть несохранённые изменения. Закрыть без сохранения?».
- Навигация мимо `index.html` запрещена. `file:` превращается в `dropUris`, остальные адреса — в `link`.
- Сочетания клавиш ловит `app.js` (Ctrl или ⌘). Меню оболочки не должно их перехватывать раньше страницы — кроме правки текста в полях (копировать, вставить, отменить).
