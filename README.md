# Mind Map — лёгкий редактор на markmap

**Русский** · [English](README.en.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [中文](README.zh.md)

*Lightweight offline mind map editor for Linux (GTK3 + WebKit2GTK, markmap): Markdown, FreeMind, OPML, XMind, PDF export. MIT.*

Просмотр и правка интеллект-карт под Linux. GTK3 + WebKit2GTK (системные пакеты), внутри — [markmap](https://github.com/markmap/markmap) 0.18.12 и d3 7.9.0, лежат локально в `web/vendor/`, сеть не нужна.

## Запуск

```sh
./mindmap.py [карта.mm.md|.mm|.opml|.xmind]
./mindmap.py карта.mm.md --pdf карта.pdf     # экспорт без интерфейса
```

Зависимости (Debian/Ubuntu): `python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1`.

## Установка

```sh
./build.sh [версия]     # по умолчанию 0.3.0 → dist/mindmap_0.3.0_all.deb и dist/mindmap.run
sudo apt install ./dist/mindmap_0.3.0_all.deb
```

Пакет ставит команду `mindmap`, ярлык «Mind Map» в меню приложений, значок и типы файлов, зависимости подтянет apt.

`mindmap.run` — то же одним файлом без установки (без ярлыка и типов файлов): при первом запуске разворачивается в `~/.cache/mindmap/<хеш>/`, дальше стартует сразу. GTK/WebKit в нём нет — нужны системные пакеты из списка выше.

### Расширение файлов: `.mm.md`

Карты стоит называть `план.mm.md` — так же, как их называет markmap (расширение для VS Code). Это обычный Markdown: его покажет GitHub и откроет любой редактор, но у него свой тип `text/x-markmap`, и двойной клик открывает карту. Обычные `.md` остаются за вашим редактором Markdown, Mind Map для них — в «Открыть с помощью». Новая карта по умолчанию сохраняется как `mindmap.mm.md`.

Пакет регистрирует ещё `.mm` (FreeMind/Freeplane) и `.xmind` — в стандартной базе типов их нет (`.mm` там — troff). Сделать Mind Map приложением по умолчанию:

```sh
xdg-mime default mindmap.desktop text/x-markmap application/x-freemind application/vnd.xmind.workbook text/x-opml+xml
```

## Возможности

- Языки интерфейса, справки и обучения: русский, английский, испанский, французский, немецкий, китайский (упрощённый). Выбирается по системной локали, для остальных — английский; принудительно — `LANGUAGE=de mindmap`.
- Масштаб: колесо, щипок на тачпаде, `Ctrl+=` / `Ctrl+-`; `Ctrl+0` — вписать в окно.
- Создание и правка карты: на графе (двойной клик по названию или списку, правое меню, клавиши) и в исходнике Markdown (`Ctrl+E` — показать/скрыть). Обе стороны синхронизируются.
- Справка — `F1` или «?»; «Файл → Обучение» — учебная карта с заданиями-флажками.
- Правка текста — прямо в узле, без отдельного поля поверх.
- «Схватил и тащи»: ветку за название — на верхнюю треть другой ветки (вставить перед), нижнюю (после) или середину (сделать дочерней). У края полотна (40 px) оно прокручивается само. Esc отменяет, Ctrl+Z возвращает. Пустое место тащит полотно.
- Ссылки: `[сайт](https://…)` — в браузере; `[файл](./доки/смета.pdf)`, `[папка](~/Документы)` — переход в файловый менеджер с выделением (ничего не запускается); `[карта](сеть.md)` — открывается здесь; `[см.](#название-узла)` — переход к узлу. Относительные пути — от папки карты.
- Файл или ссылку можно бросить на узел — появится дочерняя ветка-ссылка (картинка — `![](…)`).
- Нумерованные списки по CommonMark (`1.`, `1)`, первый номер сохраняется): «Ветки: нумерация» и «Список: нумерация» в меню ветки, в поле списка — «1. » в первой строке. Буквенных списков в Markdown нет.
- Картинки `![](фото.jpg)` в узлах, флажки `- [ ] дело` / `- [x] сделано` (клик переключает).
- Заметка под узлом — строки `> текст`, список — `> - пункт`. В .mm/.opml/.xmind заметка и список хранятся одним полем.
- Меню «Файл»: новый, открыть, сохранить, сохранить как, экспорт в PDF, выход (`Ctrl+Q`, спросит про несохранённое).
- Список под чертой узла — мелким шрифтом, сворачивается кликом по ▾/▸. Правится одним полем (двойной клик по списку, `Shift+Enter` или меню): строка — пункт, `Enter` — новая строка, `Ctrl+Enter` — готово, `Esc` — отмена. Пустые строки отбрасываются, пустое поле убирает список.
- Контекстное меню ветки: добавить дочернюю/соседнюю, переименовать, цвет (палитра, произвольный, сброс), свернуть, переместить вверх/вниз, повысить/понизить уровень, копировать/вырезать/вставить, удалить. На пустом месте: вписать, развернуть/свернуть всё, исходник, PDF.
- Клавиши: `Tab`/`Enter` — дочерняя/соседняя, `Shift+Enter` — список под узлом, `F2` — правка, `Del` — удалить, `Пробел` — свернуть, стрелки — навигация, `Alt+стрелки` — перемещение, `Ctrl+Z`/`Ctrl+Y` — отмена/повтор, `Ctrl+N/O/S/Shift+S/P/Q`.
- Форматы: Markdown (`.mm.md`, `.md`), FreeMind/Freeplane (`.mm`, XML), OPML (`.opml`, XML), XMind 2020+ (`.xmind`). Формат при сохранении — по расширению.
- Экспорт в PDF: векторный, одна страница по размеру карты.

## Хранение в Markdown

Структура — заголовки, пункты списков, абзацы (как в markmap). Цвет ветки — `<!-- color: #e15759 -->`, свёртка — штатный markmap-комментарий `<!-- markmap: fold -->`. Цвет наследуется потомками.

Список под узлом — цитата сразу под строкой узла (с отступом пункта), свёрнутый — метка `<!-- notes: fold -->`:

```markdown
## Цели <!-- notes: fold -->
> - срок: май
> - бюджет

- Первая цель
  > - метрика: NPS > 40
  - подцель
```

Обычный markmap покажет такую цитату дочерним узлом — содержимое не теряется.

## Ограничения

- Правка на графе приводит Markdown к канонической форме (списки с отступом 2 пробела, пустые строки вокруг заголовков). Файл, правленный только в исходнике, сохраняется байт-в-байт.
- В `.mm`/`.opml`/`.xmind` сохраняются текст, иерархия, свёртка (кроме OPML) и цвет (кроме XMind). Список под узлом пишется как заметка: FreeMind `richcontent NOTE`, OPML `_note`, XMind `notes`; его свёрнутость в эти форматы не попадает. Список одноуровневый. Иконки, заметки, связи и стили других редакторов при пересохранении теряются.
- XMind 8 (`content.xml`) не читается. Открытие сохранённого `.xmind` в самом XMind не проверялось.
- Формулы KaTeX и подсветка кода отключены (тянут ресурсы из CDN).
- В PDF попадают только развёрнутые ветки.

## Проверки

```sh
python3 test_formats.py      # .mm / .opml / .xmind, запись на диск
node web/mdtree.test.js      # Markdown ⇄ дерево
python3 tests/test_i18n.py   # переводы web/lang/*.json полны, якоря в картах живые
python3 tests/test_ui.py     # интерфейс в headless Chrome (синтетические события)
```
