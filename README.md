# Mind Map — лёгкий редактор на markmap

Просмотр и правка интеллект-карт под Linux. GTK3 + WebKit2GTK (системные пакеты), внутри — [markmap](https://github.com/markmap/markmap) 0.18.12 и d3 7.9.0, лежат локально в `web/vendor/`, сеть не нужна.

## Запуск

```sh
./mindmap.py [карта.md|.mm|.opml|.xmind]
./mindmap.py карта.md --pdf карта.pdf     # экспорт без интерфейса
```

Зависимости (Debian/Ubuntu): `python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1`.

Ярлык в меню приложений:

```sh
cat > ~/.local/share/applications/mindmap.desktop <<EOF
[Desktop Entry]
Type=Application
Name=Mind Map
Exec=$PWD/mindmap.py %f
Icon=x-office-drawing
MimeType=text/markdown;application/x-freemind;text/x-opml+xml;application/vnd.xmind.workbook;
Categories=Office;
EOF
```

## Возможности

- Создание и правка карты: на графе (двойной клик, правое меню, клавиши) и в исходнике Markdown (`Ctrl+E` — показать/скрыть). Обе стороны синхронизируются.
- Контекстное меню ветки: добавить дочернюю/соседнюю, переименовать, цвет (палитра, произвольный, сброс), свернуть, переместить вверх/вниз, повысить/понизить уровень, копировать/вырезать/вставить, удалить. На пустом месте: вписать, развернуть/свернуть всё, исходник, PDF.
- Клавиши: `Tab`/`Enter` — дочерняя/соседняя, `F2` — правка, `Del` — удалить, `Пробел` — свернуть, стрелки — навигация, `Alt+стрелки` — перемещение, `Ctrl+Z`/`Ctrl+Y` — отмена/повтор, `Ctrl+N/O/S/Shift+S/P`.
- Форматы: Markdown (`.md`), FreeMind/Freeplane (`.mm`, XML), OPML (`.opml`, XML), XMind 2020+ (`.xmind`). Формат при сохранении — по расширению.
- Экспорт в PDF: векторный, одна страница по размеру карты.

## Хранение в Markdown

Структура — заголовки, пункты списков, абзацы (как в markmap). Цвет ветки — `<!-- color: #e15759 -->`, свёртка — штатный markmap-комментарий `<!-- markmap: fold -->`. Цвет наследуется потомками.

## Ограничения

- Правка на графе приводит Markdown к канонической форме (списки с отступом 2 пробела, пустые строки вокруг заголовков). Файл, правленный только в исходнике, сохраняется байт-в-байт.
- В `.mm`/`.opml`/`.xmind` сохраняются текст, иерархия, свёртка (кроме OPML) и цвет (кроме XMind). Иконки, заметки, связи и стили других редакторов при пересохранении теряются.
- XMind 8 (`content.xml`) не читается. Открытие сохранённого `.xmind` в самом XMind не проверялось.
- Формулы KaTeX и подсветка кода отключены (тянут ресурсы из CDN).
- В PDF попадают только развёрнутые ветки.
